# 专业与成本协调

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

同范围的建筑与各专业成果、图纸/模型/清单修订、冲突报告、规格、预算及现场和运输条件。

## 执行

1. 确认各输入的楼栋、楼层、阶段、方案、单位和版本；建立几何与文件对应关系，未对齐的来源先列差异。
2. 检查结构、湿区管井、净高、设备检修、厨房排气、屋面/场地排水和室内外接口，定位到对象编号与图纸。
3. 对冲突区分真实几何冲突、检修空间不足、规格冲突及模型误差；修正建议结合本项目专业条件，写明责任方和需回答的问题。
4. 将可建造性问题按后期修复代价和当前决策影响排序，列运输安装、材料交接及节点深化所需证据。
5. 图纸、模型、清单和预算的数量只在同范围、同修订、同单位下比较；缺失不当作零，重复编号先确认，保留差异来源。
6. 变更按对象传播到面积、房型、动线、围护、设备、预算及交付版本；需要专业决定的移动、开孔或尺寸改变保留确认依据与复查状态。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

coordination/interface-register.csv；clash-triage.csv；可建造性问题、数量差异及变更影响表。

每项问题有位置、依据、后果、责任方与复查条件；数量匹配仅表示两份输入一致；专业状态和实际修订可追溯。

## 缺口与变更

模型定位或单位不明时先做元数据核对，不继续碰撞和工程量结论；专业回复未复查时保持未闭环。
