# 动线与交通组织

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

总图及各层平面、房间与活动清单、经营服务流程、交通和本次适用的专业要求。

## 执行

1. 为到达入住、客房往返、早餐、公区活动、清洁布草、配送垃圾及检修建立起终点明确的路径。
2. 将路径映射到实际门、走道、楼梯、坡道和电梯等节点，标明方向、使用者、时段、尺寸来源与高差。
3. 检查隐私、气味、噪声、洁污和客勤交叉；需要共享时提出时段或布置策略及运营条件。
4. 识别入口、转向及楼层切换的寻路决策点，检查夜间、雨天和携带行李的使用场景。
5. 按已核验的适用条件向消防、无障碍及交通专业交接路线和待核尺寸；没有专项依据时不能给出合规结论。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

circulation/routes.csv；分角色路径图；交叉点及高差问题表；专业核查输入。

每条路径实际连续且包含跨层节点；路径长度与净宽有几何来源；经营路径与法定疏散核查状态分别记录。

## 缺口与变更

图纸缺少门或标高时标记断点并返回责任阶段；不得为使路径连通而悄悄新增已确认门洞。
