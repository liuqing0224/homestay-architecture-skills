# 建筑校审与成果交付

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

当前选定方案、成果目录、对象清单、专业回复及复查记录、范围和接收要求。

## 执行

1. 按本次范围和成果深度检查任务书、条件、总图、平立剖、面积、客房数、开口及专业条件的版本对应。
2. 检查实际文件能打开、索引路径正确、修订与标题一致；图纸与模型/清单数量差异逐项解释，旧版单独归档。
3. 需要专业校审时提供具体依据与证据包，接入已有校审能力；校审尚未完成的成果记录状态，不用文件存在替代通过。
4. 将问题回复和图纸修订复查后再闭环，按本次交付范围记录未结事项及其对使用的影响。
5. 生成成果索引、文件哈希、版本与来源清单，向室内、景观和后续工程设计交接坐标、房间、开口、标高与待核条件。
6. 本地打包、实际发送、接收与客户选定分别记录；只有本次授权包含外发才执行相应渠道，并以实际结果更新。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

delivery/README.md；manifest.csv（文件、修订、SHA-256、用途、状态）；图纸及条件交接包；问题复查与遗留事项。

文件和索引相符；关键成果指向同一版本；声明的成果深度与已有输入、实际文件和专业状态一致。

## 缺口与变更

发现缺图、陈旧清单或未复查问题时保留工作稿，列出影响和补齐项；有条件交付须明确其使用范围与已有授权。
