# 立面屋面与气候响应

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

同版平面剖面、气候及朝向资料、景观隐私需求、材料意向、专业性能与维护要求。

## 执行

1. 从房间和活动需求确定开口位置，核对立面、平面、剖面和门窗编号；不只按外观均分立面。
2. 依据本地季节条件提出遮阳、可开启、入口防雨、风雨暴露及隐私策略，注明依据和需要计算的内容。
3. 按雨水、空气、保温与水汽等控制层检查材料和节点连续性，重点看窗边、檐口、屋面、露台、门槛与新旧交接。
4. 记录材料规格、安装及可替换条件，评估清洁、检修、地方工艺和施工可达性；没有测试或计算时不宣称性能达标。
5. 形成与模型同版的立面、屋面排水意向、开口表和节点清单，交给结构、机电、室内及成本协调。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

envelope/elevations.*；屋面及排水意向；opening-schedule.csv；材料与节点性能需求表。

开口编号与几何一致；排水去向可说明；关键控制层及接口有记录；图像不替代构造或性能依据。

## 缺口与变更

当地气候、材料或构造信息缺失时提供策略比较和待核参数；保留上一版立面及受影响开口清单。
