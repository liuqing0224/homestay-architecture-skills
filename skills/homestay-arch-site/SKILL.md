# 场地与现状分析

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

地址或坐标、测绘与红线、现状CAD/PDF、照片、地形资料、原建筑资料及已有场地记录。

## 执行

1. 建立来源清单，确认坐标、单位、北向、竖向基准及版本；照片与扫描图只有经有效标定才能提供尺寸。
2. 分开绘制边界、保留对象、地形、道路、植被、水体、排水去向和管线条件，标明实测、用户提供、推断及缺项。
3. 按所在地与设计范围检索适用的原始气候、地形和环境资料，记录发布者、地理范围、统计期及获取日期；区域概况不能替代地块勘察。
4. 从实际到达方式检查步行、车辆、接驳、行李、配送、垃圾和施工运输；交通数据的范围与时段要和项目用途对应。
5. 将景观、日照、风雨、隐私、邻里与灾害线索转为设计机会、约束和待专业核实事项，输出可追溯底图。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

site/base-plan.*；site/site-analysis.md；site/source-register.csv；缺失测量与勘察事项。

底图可识别尺度与基准；每项关键环境事实有来源和适用范围；无依据的坡度、边界和地质条件没有被固化。

## 缺口与变更

坐标、边界或标高冲突时保留原始文件，暂停依赖该条件的尺寸决策；可继续完成不依赖冲突的活动与场地研究。
