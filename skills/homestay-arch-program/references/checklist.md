# 功能与面积策划检查表

## 面积与数量

space_id/type_id、category、activity_id、quantity、unit_area_m2、total_area_m2、capacity、measurement_basis、source_id、status、revision。实例表逐间列出时，类型汇总只作为派生视图，不再加入总数。

## 邻接矩阵

用“必须连接、宜靠近、无特殊关系、需要分离”表述关系，并另列硬性禁止邻接及其依据。每对空间记录原因；双向对称的邻接与单向的服务运输路径分开。关系不能只靠一个总分掩盖必须分离条件。

## 核对

- 用房间清单、楼层图和类型统计检查可售房间是否一致。
- 墙体、楼梯、走道、设备和室外面积按口径分别列出。
- 公区容量不直接按客房数或床位数替代。
- 变化后列出被影响的房型、动线、建筑轮廓和投资测算。
