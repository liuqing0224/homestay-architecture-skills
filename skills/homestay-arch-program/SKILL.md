# 功能与面积策划

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

建筑任务书、客房及活动目标、可用面积与口径、场地及建设条件、已有空间清单。

## 执行

1. 按活动拆分客房、公区、后勤、设备、交通、墙体等面积类别；明确各类别测量边界，避免重复计入。
2. 对每一空间或类型记录稳定编号、数量、单元面积、总面积、容量、来源及假设状态；同一表内区分类型汇总与房间实例。
3. 以明确算式汇总数量×单元面积、分类小计、建筑总量与剩余；净面积、建筑面积和计容面积分别处理。
4. 建立空间对的邻接或分离要求，写出噪声、气味、隐私、服务顺序和通达理由；将关系转成气泡图及楼层分配。
5. 超出面积或投资边界时提出可比较的调整，说明增加一类空间后减少了什么；更新可售单元、床位和使用者的各自口径。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

program/space-program.csv；program/adjacency.csv；功能关系及楼层分配图；面积平衡与调整说明。

小计可复算、空间不重复、余量有解释；经营人数与法定人数分开；关系矩阵可对应到图中的对象编号。

## 缺口与变更

缺少空间面积时给出带来源状态的设计候选，不套入未经核验的固定配比；口径冲突时保留两种结果及差异。
