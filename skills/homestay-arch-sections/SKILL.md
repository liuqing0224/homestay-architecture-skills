# 剖面与地形适应

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

可靠地形与标高基准、建筑平面、功能净高需求、结构机电条件、保留建筑及排水资料。

## 执行

1. 统一现状地面、设计地坪、各层、屋面和室外活动面的竖向基准，图中区分既有与拟建。
2. 选择穿过入口、楼梯、客房、公区、湿区及高差等关键位置的剖切线，与平面编号对应。
3. 分解层高、结构及设备空间、装修和净高关系；没有专业厚度依据时保留参数及待核状态。
4. 山地项目解释每处主要挖填、挡土及排水意向，平地与改造项目按自身条件处理，不套用山地构造。
5. 复核交通跨层、室内外门槛、设备与维护高差，形成需要勘察、结构和排水专业回答的问题及影响范围。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

sections/level-register.csv；关键剖面与剖切索引；地形/挡土/排水接口及待核清单。

平剖、总图和标高一致；高差有起终点与基准；方案意向与经过计算的工程结果分开记录。

## 缺口与变更

地形或既有层高不可靠时先做参数化候选，暂停依赖绝对标高的土方或挡土定量结论。
