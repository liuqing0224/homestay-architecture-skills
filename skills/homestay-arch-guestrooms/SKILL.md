# 客房建筑模块

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

选定建筑方案、客房目标、房型与活动需求、楼层/结构条件、景观朝向及设备接口。

## 执行

1. 建立房型数据表，记录可售单元、内部房间、床位、使用人数和特殊使用需求，不把套房的多个空间重复统计为多间可售客房。
2. 以家具、行李、清洁、卫生间及设备活动范围反推房间几何，核查入口、床位、开口与景观和隐私的关系。
3. 检查相邻客房的视线、设备噪声、湿区、管井及保洁服务；差异房型单独出条件图。
4. 把房型布置到实际楼层，逐间核对面积、标高、开口和编号，比较类型重复与地形造成的变化。
5. 向室内和机电交接锁定的房间边界、结构/净高条件、湿区、开口和设备约束，保留室内深化可调整项。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

rooms/room-types.csv；rooms/room-instances.csv；典型及差异房型平面/剖面；客房建筑条件表。

房间实例与可售单元统计一致；房型设计有可读几何及标注；建筑、面积表、室内交接使用同一编号。

## 缺口与变更

结构或湿区输入缺失时先表达方案占位及状态；不把占位写成专业已确认的承重、隔声或设备方案。
