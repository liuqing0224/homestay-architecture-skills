# 场地与现状分析检查表

## 证据分层

测绘/权属资料、已发布图纸、用户确认条件与设计假设分别登记。来源之间发生冲突时，说明涉及哪一对象和决策，不静默选择更方便的尺寸。

## 场地专题

| 主题 | 核对内容 | 对方案的影响 |
|---|---|---|
| 气候 | 地点、统计期、季节差异、风雨及暴晒 | 朝向、遮阳、入口防雨、材料维护 |
| 地形与水 | 高程基准、汇水路径、周边排水、低点 | 建筑落位、首层标高、挡土与排水接口 |
| 到达 | 到达方式、最后一段路线、行李、服务车、运输 | 入口、接驳点、后勤口及施工条件 |
| 既有对象 | 可核实的结构、围护、开口及保留要求 | 保留与拆改边界、进一步调查 |

## 场地类型

山地才增加地形与边坡专题；滨水关注水位及腐蚀环境；平地不强加挡土方案；改造先核实可保留条件。没有可靠地块定位时不把其他城市或相近地块的数据代入。

外部方法标识：GH-A、GH-D。采用位置、改写说明和许可见[方法来源](../../homestay-arch-orchestrator/references/upstream-methods.md)。
