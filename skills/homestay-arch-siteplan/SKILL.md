# 总平面与场地布局

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

可靠场地底图、功能面积表、建设条件、到达及服务需求、候选体量与保留对象。

## 执行

1. 在同一底图上标明用地、保留和可建设范围，以实际来源和状态表示限制条件。
2. 组织主入口、接驳、行李、服务配送、垃圾与施工进入路径；分别检查日常经营和特殊天气的使用。
3. 比较建筑落位、庭院、客房景观与公共活动的关系，明确室内外标高和隐私、噪声接口。
4. 接入消防、无障碍、设施接入和场地排水等条件，未核实的专业需求标到图上交接。
5. 复算场地和建筑相关面积，联动出入口、地形、景观及专业条件编号，不用无尺度效果图代替总图。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

design/site-plan.*；场地分区、到达与服务路径图；室内外标高和场地接口表。

图上有比例、北向、坐标/尺寸和版本；各入口有可追踪的到达路径；规划和工程待核事项可定位。

## 缺口与变更

边界或道路条件变化时先形成新的候选修订，列明受影响建筑与路径，保留已选定版本。
