# 公共空间建筑设计

先读取[共享项目约定](../homestay-arch-orchestrator/references/project-contract.md)中与本次任务相关的部分，沿用项目已有编号和权威状态；仅执行当前要求的工作。

## 输入

活动任务书、公区面积、使用时段、客流与外部客人需求、总图、客房与后勤方案。

## 执行

1. 把公区按活动和时段展开，区分住客、外来访客与员工，保留不同峰值假设。
2. 设计抵达、接待、等候、早餐、社交、安静休息和室外活动之间的空间联系。
3. 检查多用途共享的布置转换、家具储藏、清洁、设备和人员条件，不把不可能同时兼容的活动重复计入容量。
4. 协调餐饮与备餐、卫生间、排烟、噪声、湿区及室外门槛，向相关专业提出可定位的问题。
5. 提供公区平面和关键剖面，传递家具与设备需求、控制条件及需室内深化的接口。

具体核对方法见[阶段检查表](references/checklist.md)。

## 输出与验收

public/activity-capacity.csv；公区平面与关键剖面；时段复用和专业接口表。

容量可对应活动布置；住客与外来访客范围清楚；公区、后勤和客房之间的关系可核对。

## 缺口与变更

活动范围未定时给出可切换方案与面积代价，不虚构经营活动已确定或活动许可已取得。
